# Split Test Tool

Self-serve **A/B testing (split testing)** SaaS for small teams and marketers — simple setup, transparent pricing, no enterprise sales cycle.

## Product direction (summary)

- **Customer:** Sign up → install snippet → create A/B test → track one primary goal → read results → upgrade by traffic.
- **Us:** Multi-tenant app (auth, billing, dashboard) + lightweight tracking snippet + experiment API.
- **Not first:** Enterprise SSO, full CRO suite, warehouse-only analytics, or visual editor on every SPA.

See the [launch scope doc](docs/COMPETITIVE_ANALYSIS_AND_LAUNCH_SCOPE.md) for detail.
